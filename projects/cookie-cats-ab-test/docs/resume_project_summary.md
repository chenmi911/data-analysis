# 简历项目表述

## 项目名称

手游关卡门槛调整的 A/B 测试与留存分析

## 项目描述

基于 Cookie Cats 90,189 名玩家的随机分流实验（gate_30 44,700 / gate_40 45,489，分流 49.6% / 50.4%），使用 MySQL 评估将第一个等待门槛从第 30 关后移至第 40 关，对 1 日/7 日留存及前 14 天游戏局数的影响，为产品数值调整提供量化依据。

## 核心职责与技术

- 使用 MySQL 完成 CSV 导入、布尔字段清洗、唯一用户和缺失值检查（90,189 行零缺失、零重复 userid），以及 A/B 组样本均衡性核验（49.6% / 50.4%）。
- 使用 CTE、条件聚合和双比例 Z-Test，在 SQL 中计算 1 日、7 日留存的组间差异、双侧 p 值和 95% 置信区间；p 值采用标准正态分布近似实现，并将检验逻辑封装成视图，留存明细与决策证据共用同一实现。
- 使用 `ROW_NUMBER()` 等窗口函数构建 P50-P99 游戏局数分位数（中位数 16-17、P99≈493、峰值 49,854），识别长尾极值对均值的干扰，并将活跃度作为辅助决策指标。

## 项目成果

- 主结论：`gate_40` 的 7 日留存较 `gate_30` 低 0.82 个百分点（约 -4.3%，p = 0.0016，95% CI [-1.33, -0.31] 个百分点）；辅助指标方向一致（1 日留存 -0.59 个百分点）或无差异（游戏局数分位数），按既定决策规则建议不推广第 40 关方案。
- 业务量级换算：-0.82 个百分点约等于本批 45,489 名实验组玩家中少 370 名第 7 天留存用户（相对留存用户池约 -4.3%）。
- 口径辨析（选择偏差）：全体样本中 62.7%（gate_30）/ 69.6%（gate_40）玩家前 14 天未触达各自门槛；若只看“到达者”，结论会反转成 gate_40 更高（+4.6 个百分点，p < 0.001），这是后处理选择偏差所致，不能作因果依据。以“两组都打过 ≥ 40 局”的同投入度样本复核，方向仍为 gate_40 低约 1.8 个百分点（p = 0.003）。故以全体样本（ITT）为因果主口径。

## 使用边界

该数据不包含收入、广告、付费和关卡进度明细，项目结论限定为留存与活跃度影响，不能外推为商业化收入或长期商业价值结论。
